# Seu Site Aqui

Landing page de divulgação do meu trabalho de criação de sites para empresas e comércios.

Feita em HTML, CSS e JavaScript puros, sem dependências. É só abrir o `index.html` no navegador.

## Estrutura

- `index.html`: conteúdo da página
- `style.css`: estilos (cores no `:root`)
- `script.js`: animações e interações
- `img/`: imagens
